## Что делаем (и только это)

### 1. Кнопка AI-ассистента — заметнее

Файл: `apps/web/src/components/assistant/AssistantLauncher.tsx` (рендерится в топ-баре `apps/web/src/app/(main)/layout.tsx:126`, видна на всех страницах `(main)`).

Сейчас — обычная pill-кнопка (`Sparkles` + «AI-ассистент», серая рамка). Меняем:
- **Крупнее и заметнее** остальных кнопок топ-бара.
- **Анимированная градиентная рамка** по референсу Google Gemini — плавное движение цвета по контуру. Чистый CSS (`@keyframes` + `conic-gradient`/`background-position`), без JS-анимации и без внешних библиотек. Свечение не должно мешать читать подпись.
- Уважать `prefers-reduced-motion` — при включённом отключать анимацию (статичный градиент).

### 2. Индикатор «1» для новичка

На кнопке — бейдж непрочитанного «1», пока пользователь ни разу не открыл ассистента. Исчезает после первого открытия.

Механика хранения (per-user, не per-device — как `toursCompleted`): **рекомендую переиспользовать `UserProfile.toursCompleted`** (`packages/db/prisma/schema.prisma`) — добавить маркер `'assistant'` при первом открытии. Без новой миграции. Альтернатива — отдельное поле `assistantOpenedAt DateTime?` (аддитивная миграция). Решение — на этапе плана; toursCompleted проще.

Логика бейджа: показываем, если `'assistant' ∉ toursCompleted`. На первом открытии — мутация, добавляющая маркер (best-effort, не блокирует открытие).

### 3. Сценарий первого сообщения

Файл: `apps/web/src/components/assistant/AssistantConversation.tsx` (сейчас приветствия нет — пустой диалог).

При первом открытии (пустая история) ассистент показывает приветствие по имени и понятные сценарии-чипы:

> «{Имя}, привет! Я помогу быстро сориентироваться в Академии. Опишите задачу или вопрос — я подберу нужный урок, инструкцию, чек-лист или шаблон.»

Чипы-сценарии (клик = засев запроса):
- подсказать, с чего начать;
- найти материал по конкретной задаче;
- помочь разобраться с рабочей проблемой;
- провести в нужный раздел платформы.

Это **клиентский приветственный стейт**, а не реальное сообщение ассистента (не тратим квоту/LLM). Имя — из профиля; если пусто — нейтральное «Привет!». Чип подставляет текст в поле ввода (или сразу отправляет — решить на плане; подстановка мягче).

### 4. Переименование раздела «Решения»

Чистый копирайт, пройти консистентно по всем местам:
- `apps/web/src/components/shared/sidebar.tsx:25` — «Решения под задачу» → **«Решения»**.
- `apps/web/src/app/(main)/dashboard/page.tsx:35` — кнопка «Решить задачу» → **«Найти решение»**.
- Grep остальных вхождений «Решения под задачу» / «Решить задачу» в `apps/web/src` — переименовать все, включая заголовки страницы `/learn/solutions`, хлебные крошки, любые CTA.

Тон — по редполитике (скилл `mpstats-copywriting`).

## Границы

**Не делаем:** вынос статистики/серий/«Продолжить»/«Под твою задачу»; встроенный ассистент прямо в тело главной; любые изменения логики самого ассистента (RAG, квоты, концьерж). Только заметность кнопки + приветствие + переименование.
